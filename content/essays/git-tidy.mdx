One of my repos had a long list of branches to review: merged features, abandoned experiments, and `sync-main-to-dev-*` branches that automation kept creating.

> `git-tidy` is a small CLI that finds stale Git branches, previews what it would delete, protects important branches, and only deletes after you explicitly run it.

Deleting them by hand is the kind of chore I'll avoid for months, partly because it's boring and partly because I'm scared of nuking a branch that had work I forgot about. So I made [git-tidy](https://www.npmjs.com/package/git-tidy-cli).

```bash
npx git-tidy-cli
```

The tool can filter for merged branches and skip protected names such as `main` and `develop`. Age and pattern filters can also match unmerged branches, so I read the preview before deleting anything. Dry run is the default; the first command prints candidates without deleting them.

It also has a `--json` mode, which means I can point an agent at it: "tidy the merged branches older than 90 days on origin" and it shows me the list before touching anything.

The first time I used it for real I nearly made a mess. I wanted to clear out old sync branches, so I ran `--pattern 'sync-*' --age 7`. The dry-run came back with about half the repo. Took me a second to realise the filters were OR'd: it read that as "sync branches, or anything older than a week." Not what I meant.

<Note>The preview let me catch the filter mistake before deleting anything.</Note>

So I added a `--match all` flag for when you want every condition to hold:

```bash
git-tidy --match all --pattern 'sync-*' --age 7 --scope remote
```

<Note>`--age 7` checks the tip commit’s author date, not when the branch was created.</Note>

Then I used it on three repos. I read each preview before executing. Most of the candidates were old sync branches from a bot that had never been cleaned up.

That's the whole tool. It's on [npm](https://www.npmjs.com/package/git-tidy-cli) and [GitHub](https://github.com/iarmankhan/git-tidy). If you try it on a repo with a lot of old branches, start with the preview and check every candidate.
